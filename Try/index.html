Intent

A haunted house looks like a pile of spooky props, but it behaves like a system: a handful of element categories (location, core, concealment, visual add-on, audio add-on, optional strategy) are combined into encounters, and the encounters are sequenced to steer a group’s movement, attention and emotion. I wanted to model the designer’s side of this: you assemble a house, send a group of visitors through it, and watch how the pieces affect each other and the visitors.

Process

  1. Element catalogue. From my category chart I defined every legal element: Room (4 slots) and Corridor (2 slots); cores Actor, Installation, Stationary; concealments Door, Screen, Shutter, Display; add-ons Darkness, Flashing Light, Sudden Sound; strategies Visual Block, Visual Cue, Direction Change.
  2. Rules as constraints. A Visual Cue is a core + (Display or no concealment) + optional Flashing Light, so the editor only offers those options for it. Default lighting and sound are implied everywhere.
  3. UML. Each category became a class; a House is composed of Locations, a Location of Encounter slots, and an Encounter of one element per category. Visitors are separate agents that react to encounters.
  4. Behaviour. I gave encounters no fixed “scare value”. They only emit stimuli; the visitor’s state decides the result, which is where emergence comes from.
  5. Sample house. The 12-encounter example from my guide is built in as a preset (the sample corridor has four encounters, so it is modelled as two 2-slot corridors).

Emergent properties

No encounter has a built-in “scariness”. The same encounter can be a great scare or a wasted prop depending on its neighbours:

  • Misdirection. A visitor watching a Visual Cue is far more vulnerable to a jump scare that follows (the sample’s #3 → #4).
  • Anticipation. Visual Blocks and Direction Changes raise anticipation, which multiplies later scares.
  • Habituation. Repeating the same core type makes it less effective for that visitor.
  • Numbness. Scares packed too tightly dull the visitor’s response.
  • Contagion and panic. Fear spreads between nearby visitors; a visitor who panics at 100 runs out, so every later encounter is wasted on them. The bar chart shows the average fear each encounter produced.
